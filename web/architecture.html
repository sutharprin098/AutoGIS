NS-VGP 1.0

VeriGeo Runtime Verification Protocol

Neuro-Symbolic Guardian against Silent Spatial Hallucinations

General LLMs check only Python syntax. If code exits with Exit Code 0, they assume success — even when geographic calculations are distorted by 35% or correlations flip signs. VeriGeo enforces four non-negotiable scientific axioms:

Axiom 1 (Projections): Equal-Area CRS (e.g. EPSG:6933, EPSG:5070) is mandatory for carbon, area, and density sums; Metric UTM is mandatory for buffer distances.
Axiom 2 (MAUP & Tobler): Intensive ratios (income, NDVI, density) must never be summed in spatial joins. Applies 35-pass pycnophylactic smooth interpolation to conserve total counts.
Axiom 3 (Topology): Detects micro-geometry slivers ($circularity < 0.05$ and width < 1.0m), snaps dangling nodes, and auto-repairs self-intersecting rings.
Axiom 4 (Physical Conservation): Enforces thermodynamic limits ($\text{NPP} \le 3500\text{ g C/m}^2/\text{yr}$) and hydrological mass balance ($\sum \text{Outflow} \le \text{Precipitation}$).

GAS 1.0.0

Geospatial Agentic Services Mesh

OGC-Style Standard Protocol for Distributed Geo-Agents (GIBD Lab)

AutoGIS connects natively to the Geospatial Agentic Services (GAS 1.0.0) ecosystem, allowing local QGIS workflows to discover, delegate, and execute specialized tasks on remote agent nodes across research institutions:

Discovery (GetCapabilities): Discovers registered agents via gas_discover_agents and distributed registries via gas_registry_search.
Inspection (DescribeAgent): Inspects skills, JSON input parameter schemas, and real-time operational status via gas_describe_agent.
Execution Modes: Supports synchronous execution, live Server-Sent Events (SSE) token streaming, and asynchronous polling for long-running compute jobs.
Artifact Auto-Loading: Spatial GeoJSON, Shapefiles, and GeoTIFFs returned by remote agents are automatically loaded directly onto the QGIS map canvas.
Standards: GIBD Lab GAS 1.0.0 Protocol 5 Native Tools
