VeriGeo Runtime Guardian

NS-VGP 1.0 Protocol

Neuro-Symbolic guardian eliminating silent spatial hallucinations. General LLMs check only Python syntax; VeriGeo enforces non-negotiable scientific axioms:

Axiom 1 (Projections): Equal-Area CRS for area/carbon sums; Metric UTM for buffer distances.
Axiom 2 (MAUP Guard): 35-pass pycnophylactic smooth interpolation prevents summing intensive ratios.
Axiom 3 (Topology): Auto-prunes micro slivers ($circ < 0.05$) and snaps self-intersecting rings.
Axiom 4 (Thermodynamics): Enforces thermodynamic limits and hydrological mass conservation.

Geospatial Agentic Services

GAS 1.0.0 OGC Mesh

OGC-style standard protocol by GIBD Lab connecting local QGIS workflows to distributed remote agent nodes across research institutions:

Discovery: Discovers published remote agents across university registries via gas_registry_search.
Schema Negotiation: Inspects JSON parameter schemas and agent status via gas_describe_agent.
Live SSE & Async: Supports synchronous tasks, live streaming tokens, and async compute jobs.
Canvas Draping: Returned GeoJSON, Shapefiles, and GeoTIFFs auto-drape directly into QGIS layers.
Standards: GIBD Lab GAS 1.0.0 5 Native Tools

User Prompt: "Run deep Sentinel-1 SAR radar crop classification over Punjab using the remote GIBD Lab GAS Agent."
STEP 1

GAS Discovery

Calls gas_registry_search to discover the active remote SAR crop classification agent on the GAS 1.0.0 network.

STEP 2

Schema Negotiation

Executes gas_describe_agent to fetch JSON parameter requirements, bounding box coordinate types, and expected SAR polarization channels.

STEP 3

Remote Task Dispatch

Calls gas_execute_task in streaming mode. Receives live status updates and intermediate backscatter processing telemetry.

STEP 4

VeriGeo & Canvas Draping

VeriGeo audits the returned classification raster for projection integrity; AutoGIS automatically drapes the classified crop zones onto the QGIS canvas.
