Step-by-Step Execution Scenarios

Select a real prompt below to see exactly how AutoGIS activates each module.

User Prompt: "Find optimal 500MW solar park sites in Rajasthan using 100+ environmental and technical criteria."
STEP 1

Geocoding & STAC Crawl

Resolves Rajasthan bounds, fetches Sentinel-2 L2A (<15% clouds), Copernicus 30m DEM, and NASA POWER GHI (5.92 kWh/m²).

STEP 2

100+ Layer Datacube

Assembles 100 criteria into 512x512 tile chunks in memory-mapped GeoParquet + COG. RAM stays under 45MB.

STEP 3

VeriGeo Axiom Check

Harmonizes coordinates to UTM Zone 43N (EPSG:32643), enforces equal-area projection, and verifies surface solar radiation limits.

STEP 4

Hybrid MCDM & QGIS Map

Computes AHP + Shannon Entropy weights, solves Fuzzy TOPSIS raster suitability [0–100], and renders ranked polygon layers on QGIS canvas.

User Action: Uploaded "Thar_Solar_EIA_Report.pdf" with query "What is the buffer distance and coordinates?"
STEP 1

AI Router Inspection

AI Document Router checks user's Xerj API key and scans spatial entity density (Score: 1.0 > 0.25 threshold).

STEP 2

Xerj Reader-1 Dispatch

Dispatches document to platform.xerj.ai/v1/answers. Generates symbolic checked program in 230 ms.

STEP 3

Typed Evidence Quotes

Extracts typed values: 500m wildlife buffer, coordinates 27.1823°N, 71.9321°E, and EPSG:32643 with 99.3% confidence.

STEP 4

Automated Buffer on Map

AutoGIS passes extracted parameters directly into PyQGIS toolchain, drawing the exact 500m exclusion polygon.

User Prompt: "Aggregate census population into new watershed flood zones and remove overlay boundary slivers."
STEP 1

Semantic Attribute Typing

VeriGeo classifies attributes into intensive ratios (median income, pop density) vs extensive counts (headcount).

STEP 2

Pycnophylactic Interpolation

Applies Tobler's smooth pycnophylactic interpolation across zones. Eliminates 169% population overcount error.

STEP 3

Sliver & Gap Auto-Heal

Scans polygon fragments. Any sliver with circularity < 0.05 and width < 1.0m is automatically pruned and rings closed.

STEP 4

Verified Audit Certificate

Exports output with an immutable SHA-256 Spatial Proof Certificate certifying zero MAUP bias and clean topology.

Why Code Errors Aren't Enough

Standard GIS agents check only Python syntax (`Exit Code 0`). But unprojected degrees cause 35% area errors, and boundary aggregations flip statistical signs (MAUP). AutoGIS embeds domain physics into the compiler loop.

The 100+ Layer Scalability Trick

Loading 100 rasters into RAM crashes any machine. AutoGIS streams tiled windows ($512\times 512$) using lazy Dask/Xarray evaluation, computing continental decision surfaces with under 50MB RAM.

Zero-Input Autonomy

Instead of requiring users to hunt for satellite files, AutoGIS crawls open STAC catalogs, NASA POWER climatology, and OpenStreetMap automatically, converting natural language into production datasets.
