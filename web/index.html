New in Release v1.0.3

Deep Google Earth Engine (GEE) Integration

AutoGIS now communicates natively with Google Earth Engine's multi-petabyte satellite catalog. Download DEMs, query Sentinel-2/Landsat collections, export multispectral bands, and calculate cloud-free spectral indices directly into your active QGIS canvas.

01

Direct DEM Download & Terrain

Call gee_download_dem with any place name (e.g. "Kullu, Himachal") or bounding box to download a high-resolution GeoTIFF from USGS SRTM or Copernicus 30m DEM and load it into QGIS.

02

Multispectral Band Exports

Extract custom band combinations via gee_export_image across Sentinel-2 Level-2A (B4, B3, B2 for True Color, B8 for NIR) or Landsat 8/9 with automated cloud masking and spatial clipping.

03

Autonomous Spectral Indices (NDVI / NDWI)

Run gee_compute_index to calculate Normalized Difference Vegetation Index (NDVI), Water Index (NDWI), or Burn Ratio (NBR) directly on Earth Engine servers and stream the resulting GeoTIFF into QGIS.

04

Collection Filter & Metadata

Inspect satellite availability with gee_image_collection by date range, cloud-cover threshold, and spatial extent before downloading large datasets.

05

Instant Web Thumbnails

Generate 1024px PNG thumbnail preview URLs instantly using gee_image_preview to verify image quality and scene coverage without consuming local disk space.

06

Universal Geospatial Reasoning

Fully unconstrained agent engine. AutoGIS synthesizes live GEE rasters with OpenStreetMap road networks, administrative boundary polygons, and QGIS Processing algorithms in a single prompt.

Core Architecture

Engineered for Complex Spatial Workflows

AutoGIS is built specifically for GIS professionals, remote sensing researchers, and spatial analysts who need reliable, non-blocking execution across large projects.

PHASE ENGINE

Step-by-Step Task Decomposition

Automatically breaks large 30+ layer workflows into sequential phases (update_agent_plan), executing 1–2 tools per turn with 35ms UI pacing so QGIS stays responsive.

CRS INTELLIGENCE

Automatic Metric UTM & CRS Alignment

Audits Project CRS vs. Layer CRS (meters vs. degrees). Automatically reprojects EPSG:4326 layers to their local UTM Zone before buffering and aligns CRSs before spatial overlays.

TOKEN OPTIMIZED

65% Lower Token Consumption

Compact single-line project state serialization and sliding-window tool history compaction keep API token consumption minimal even on multi-layer projects.

LIVE DATA & GEE

GEE, OSM, STAC & Road Routing

Download administrative boundaries (Nominatim), live OpenStreetMap vectors (Overpass API), OSRM road routes, STAC COGs, and Google Earth Engine satellite imagery in real time.

DOCUMENT READER

Large PDF, GeoPDF & Folder Reader

Attach 200+ page PDF reports, GeoPDF maps, Word (.docx), Excel (.xlsx), CSVs, or project folders with instant page pagination and keyword search.

Step 1 — 30 Seconds

Install Plugin in QGIS Desktop

  1. 1
    Download Package: Save AutoGIS.zip (v1.0.3) to your computer.
  2. 2
    Open Plugin Manager: In QGIS Desktop, click Plugins -> Manage and Install Plugins...
  3. 3
    Install from ZIP: Select Install from ZIP on the left, choose AutoGIS.zip, and click Install Plugin.
Optional: QGIS Custom Repository XML URL
https://raw.githubusercontent.com/sutharprin098/AutoGIS/main/plugins.xml
Step 2 — 20 Seconds

Connect AI & Google Earth Engine

  1. 1
    Open Settings: Click Settings in the top-right header of the AutoGIS panel.
  2. 2
    Select Provider & API Key: Choose Google Gemini, OpenAI, Anthropic, DeepSeek, or OpenRouter, paste your key, and click Test (<2s check).
  3. 3
    Optional Google Earth Engine: In the GEE tab, enter your Google Cloud Project ID or click Authenticate GEE for seamless Earth Engine catalog access.
