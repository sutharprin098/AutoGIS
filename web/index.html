PHASE ENGINE

Step-by-Step Task Decomposition

Automatically breaks large 30+ layer workflows into sequential phases (update_agent_plan), executing 1–2 tools per turn with 35ms UI pacing so QGIS stays responsive.

CRS INTELLIGENCE

Automatic Metric UTM & CRS Alignment

Audits Project CRS vs. Layer CRS (meters vs. degrees). Automatically reprojects EPSG:4326 layers to their local UTM Zone before buffering and aligns CRSs before spatial overlays.

TOKEN OPTIMIZED

65% Lower Token Consumption

Compact single-line project state serialization and sliding-window tool history compaction keep API token consumption minimal even on multi-layer projects.

Step 1 — 30 Seconds

Install Plugin in QGIS Desktop

  1. 1
    Download Package: Save AutoGIS.zip (v1.0.0) to your computer.
  2. 2
    Open Plugin Manager: In QGIS Desktop, click Plugins -> Manage and Install Plugins...
  3. 3
    Install from ZIP: Select Install from ZIP on the left, choose AutoGIS.zip, and click Install Plugin.
Optional: QGIS Custom Repository XML URL
https://raw.githubusercontent.com/sutharprin098/AutoGIS/main/plugins.xml
Step 2 — 20 Seconds

Connect Your AI Model

  1. 1
    Open Settings: Click Settings in the top-right header of the AutoGIS panel.
  2. 2
    Select Provider & API Key: Choose Google Gemini, OpenAI, Anthropic, DeepSeek, or OpenRouter, paste your key, and click Test (<2s check).
  3. 3
    Choose Model & Save: Pick your preferred model from the synced dropdown (or enter any custom Model ID) and click Save.

100% Pure Python Codebase

Clean-Room Modular Architecture

__init__.py & plugin.py

Exposes classFactory(iface), manages QGIS toolbar/menu actions, binds Ctrl+Shift+G, and stops all timers on unload.

core/config.py

Persists settings in QgsSettings, orders models by active provider, and handles automatic model fallback chains.

core/agent_engine.py

Runs the 30-step ReAct loop, compact project state serializer, history compaction, and 35ms main-thread tool dispatcher.

core/gis_tools.py

18 native PyQGIS tools with automatic metric UTM CRS reprojection, overlay CRS alignment, raster band stats, and Processing runner.

core/live_data_tools.py

Connectors for OSM Overpass (multi-mirror failover), Nominatim boundaries, OSRM road routes, and Planetary Computer STAC COGs.

core/document_tools.py & ui/*

Large PDF/GeoPDF/DOCX/XLSX/folder reader plus High-DPI 512x512 vector logo renderer, left-timer banner, and compact dock UI.
