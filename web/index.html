Complete Technical Documentation

Configuration, CRS Engine & Workflows

1. Unified 5-Provider Setup

By default, no provider or model is pre-selected. Open Settings in the AutoGIS header to configure your preferred gateway:

  • Google Gemini: Direct API (gemini-2.5-flash, gemini-2.5-pro, gemini-2.0-flash)
  • OpenAI (ChatGPT): Direct API (gpt-4o-mini, gpt-4o, o3-mini)
  • Anthropic (Claude): Direct API (claude-sonnet-4.5, claude-haiku-4.5)
  • DeepSeek: Direct API (deepseek-chat V3, deepseek-reasoner R1)
  • OpenRouter Gateway: Access all paid & free models (nemotron-3-ultra:free, gemma-4-31b:free) with automatic fallback on HTTP 429.

2. Automatic CRS Intelligence

AutoGIS prevents the most common GIS error — running metric buffers or overlays on unaligned Geographic (EPSG:4326) layers:

  • Project CRS Audit: get_project_overview reports every layer's CRS, unit (meters vs degrees), and flags any crs_mismatches.
  • Smart Metric Buffering: When spatial_buffer is called on an EPSG:4326 layer with distance >= 0.5, AutoGIS computes the exact local UTM Zone (EPSG:326XX / 327XX) from the layer centroid, reprojects in-memory, and buffers accurately in meters.
  • Overlay Auto-Alignment: spatial_overlay automatically reprojects the overlay layer to match the input layer's CRS before running clip, intersection, difference, or union.

3. Execution Modes & Token Saver

Switch execution modes anytime from the bottom composer bar while keeping token usage minimal:

  • Auto (Autopilot): Executes read and write GIS tools autonomously up to 30 steps per turn, decomposed into clear phases.
  • Ask (Write Approval): Runs read/inspection tools automatically and prompts for confirmation before modifying or creating layers.
  • Chat Only: Pure geospatial Q&A and PyQGIS code generation without tool execution.
  • Context Compaction: Summarizes older tool outputs (>4 steps ago) to 700 chars so multi-phase runs stay fast and economical.

Module-by-Module Python Breakdown

__init__.py & plugin.py

Exposes classFactory(iface), registers toolbar/menu actions, binds Ctrl+Shift+G, and stops all timers cleanly on plugin unload.

core/config.py

Manages QgsSettings persistence, 5 AI provider endpoints, provider-ordered model catalogs, and automatic rate-limit fallback chains.

core/agent_engine.py

Implements the 30-step autonomous ReAct loop, compact project prompt builder, history compaction, and 35ms non-blocking main-thread tool dispatcher.

core/gis_tools.py

18 native PyQGIS tools including automatic metric UTM CRS reprojection, overlay CRS alignment, raster band statistics, symbology, and Processing runner.

core/live_data_tools.py

Live spatial connectors for OSM Overpass (multi-mirror), Nominatim/Photon boundaries, OSRM routing, STAC COGs, and saved QGIS servers.

core/document_tools.py & ui/*

Universal large PDF/GeoPDF/DOCX/XLSX/folder reader plus High-DPI 512x512 logo renderer, left-timer banner, and compact dock UI.
